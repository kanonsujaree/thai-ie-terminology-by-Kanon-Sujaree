# Where to look, and how

Verify every URL by searching/fetching before citing it; sites move. If a page is not reachable, say so.

## Tier 1 – ราชบัณฑิตยสภา
- ระบบสืบค้นศัพท์บัญญัติ / คลังคำ (search "ศัพท์บัญญัติราชบัณฑิตยสภา <English term>")
- พจนานุกรมศัพท์วิศวกรรมศาสตร์ (and related technical-term dictionaries: statistics, mathematics, computer, industrial/management)
- พจนานุกรม ฉบับราชบัณฑิตยสภา for general Thai words, and the transliteration (ทับศัพท์) rules
- Query patterns: `site:royin.go.th "<term>"`, `ศัพท์บัญญัติ "<term>"`, `"<English>" ภาษาไทย ราชบัณฑิตยสภา`

## Tier 2 – Thai academic usage
- ThaiJO (thaijo.org) – journals in industrial engineering, logistics, quality
- TDC / ThaiLIS (tdc.thailis.or.th) – theses and dissertations
- University IE department course outlines (มคอ.3), textbooks from Thai publishers
- Query patterns: `"<English>" "<Thai candidate>" วิศวกรรมอุตสาหการ`, `filetype:pdf <Thai term> ตำรา`

## Tier 3 – Standards and professional bodies
- สมอ. (tisi.go.th) – มอก. standards and ISO Thai translations (quality, safety, OHS)
- สภาวิศวกร, วิศวกรรมสถานแห่งประเทศไทยฯ (วสท.), IE/quality/logistics associations
- Ministry of Labour OHS regulations for safety/ergonomics wording

## Tier 4 – General web
Use for frequency checks only. Search result counts are a rough signal, not proof.

## Recording
For each candidate keep: Thai term, source name, URL, tier, type (บัญญัติ/ทับศัพท์/นิยมใช้), date accessed.
