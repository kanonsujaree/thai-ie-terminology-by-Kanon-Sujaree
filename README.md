# thai-ie-terminology

สกิลสำหรับ Claude ที่ช่วย **ค้นหา ตรวจสอบ และรวบรวมศัพท์ภาษาไทยสาขาวิศวกรรมอุตสาหการ** สำหรับงานวิจัย วิทยานิพนธ์ และการเขียนตำรา

## ทำอะไรได้
- ค้นศัพท์ไทยของคำอังกฤษ (เช่น queueing theory, makespan, standard time) จากแหล่งเรียงตามความน่าเชื่อถือ: ราชบัณฑิตยสภา → ตำรา/วิทยานิพนธ์/วารสารไทย → มาตรฐานและสมาคมวิชาชีพ → เว็บทั่วไป
- แสดงทุกตัวเลือกที่พบ พร้อมคำแนะนำ เหตุผล ประเภท (ศัพท์บัญญัติ / ทับศัพท์ / นิยมใช้) แหล่งอ้างอิง และระดับความมั่นใจ (สูง/กลาง/ต่ำ)
- ช่วยทำอภิธานศัพท์ให้ตรงกันทั้งเล่ม และเตือนคู่คำที่สับสนง่าย (เช่น variance vs variation, tardiness vs lateness)
- ครอบคลุม: วิจัยดำเนินงาน, การผลิต/โลจิสติกส์/ซัพพลายเชน, คุณภาพ/สถิติ, การยศาสตร์/ความปลอดภัย/ศึกษางาน

## วิธีติดตั้ง
1. ดาวน์โหลดไฟล์ `thai-ie-terminology.skill` จากหน้า Releases หรือจากโฟลเดอร์หลักของ repo นี้
2. เปิดไฟล์ในแอป Claude แล้วกด **Save skill** (ปุ่มจะขึ้นเมื่อองค์กรของคุณอนุญาตให้ติดตั้งสกิล)
3. เริ่มแชทใหม่ แล้วถามได้เลย เช่น "ช่วยหาศัพท์ไทยของ safety stock และ bullwhip effect สำหรับตำรา IE"

## ตัวอย่างคำถาม
- "ช่วยทำอภิธานศัพท์เรื่องการจัดตารางการผลิต: job shop scheduling, makespan, tardiness"
- "variance กับ variation ควรใช้คำไทยว่าอะไร แยกกันยังไง"

## ข้อควรรู้
- สกิลค้นเว็บสดทุกครั้ง ไม่มีฐานข้อมูลศัพท์ในตัว จึงต้องเปิดใช้เครื่องมือค้นเว็บ
- เว็บราชบัณฑิตยสภามักเข้าไม่ได้จากสภาพแวดล้อมค้นหา สกิลจะแจ้งตรงๆ ว่ายังไม่ยืนยันกับแหล่งทางการ ควรตรวจกับพจนานุกรมศัพท์ราชบัณฑิตยสภาก่อนตีพิมพ์
- ผลการทดสอบรอบแรก (3 เคส): สกิลผ่านเกณฑ์ 14/14 ข้อ เทียบกับ 8/14 ข้อเมื่อไม่ใช้สกิล โดยเด่นเรื่องแหล่งอ้างอิงและป้ายความมั่นใจ
